# Сервис управления задачами

Микросервисное веб-приложение для управления задачами с сохранением данных в PostgreSQL, подсчётом аналитики и журналом уведомлений.

## Состав проекта
* **`task-api` (порт 8080)** — главный сервис (CRUD задач, веб-интерфейс и `/health`).
* **`analytics-service` (порт 8081)** — сервис подсчёта созданных и изменённых задач.
* **`notification-service` (порт 8082)** — сервис хранения истории уведомлений.
* **`db` (порт 5432)** — база данных PostgreSQL 16 (с сохранением данных в volume `db_data`).
