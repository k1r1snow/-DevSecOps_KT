# Система заявок в поддержку

Учебный проект для системы заявок в службу поддержки.

Пользователь может создать заявку, указать её тему и описание. Сотрудник поддержки может просматривать заявки и изменять их статус.

## Основные возможности

* создание заявки;
* просмотр заявок;
* изменение статуса заявки;
* добавление комментариев;
* обработка заявок сотрудником поддержки.

## Статусы заявки

* Новая — заявка только что создана
* В работе
* Решена
* Закрыта

## Заявки

Заявка содержит тему, описание и текущий статус.

Пользователь может создать заявку и отслеживать её состояние.
## Разрешение конфликта

Конфликт возник в строке, описывающей статус «Новая», при слиянии `feature/status` в `main`. В двух ветках эта строка была изменена по-разному. Конфликт был разрешён вручную в пользу итогового варианта описания статуса.
