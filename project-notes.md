# Заметки проекта

## Тема

Система заявок в поддержку.

## Назначение

Система предназначена для регистрации и обработки обращений пользователей в службу поддержки.

## Основные сущности

* Пользователь
* Заявка
* Сотрудник поддержки
* Комментарий

## Жизненный цикл заявки

Новая → В работе → Решена → Закрыта
