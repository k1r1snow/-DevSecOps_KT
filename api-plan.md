# План API

## Заявки

### Создание заявки

`POST /tickets`

Создание новой заявки пользователя.

### Получение списка заявок

`GET /tickets`

Возвращает список заявок.

### Получение заявки

`GET /tickets/{id}`

Возвращает информацию о конкретной заявке.

### Изменение статуса

`PATCH /tickets/{id}/status`

Изменяет статус заявки.

### Добавление комментария

`POST /tickets/{id}/comments`

Добавляет комментарий к заявке.
